# M07-E — Model-native steel identity, settings, and demand path

Status: PLANNED. Parent: M07 (accepted S2). Priority: **next**.  
Maps to steel design pack **§31 Phases 1–3** and **§32 recommended first production slice**.  
Authority: ADR 0008, `docs/design/M07-WORKFLOW/structural-workbench-steel-design-spec.md`.

## Outcome

A modelled member can be steel-checked with **catalogue W properties and design inputs from the project**, simultaneous demands from the current analysis result, and an explicit first-order / effective-length design basis — without loading AISC example seed overlays.

## Scope (owned only here)

| Pack phase | Work |
| --- | --- |
| 1 Identity | Section catalogue abstraction; design section + material refs on members; recognised section/material in UI/report |
| 2 Settings | `DesignValue` provenance; Ky/Kz/Lb/Cb; initial bracing-segment representation; **member design readiness** |
| 3 Demand | Remove silent seed overlay; demands from current results with governing action identity |

Also: schema/protocol/commands so settings survive save/reopen/undo and invalidate stale design results. Rust remains authoritative.

## Acceptance (DW-E1–DW-E6)

- **DW-E1 Binding:** Supported W designation resolves to versioned catalogue props; provenance shown.
- **DW-E2 No silent seed:** Model-native path does not use example payload overlays; negative test for the old path.
- **DW-E3 Inputs:** Ky/Kz/Lb/Cb (and bracing in scope) editable with Catalogue / Project default / Derived / User / Not provided.
- **DW-E4 Readiness:** Incomplete section/material/bracing/combinations yield READY-incomplete, not PASS.
- **DW-E5 Stability basis:** UI + report declare first-order + user Ky/Kz (or UNSUPPORTED); no implied second-order.
- **DW-E6 Persistence:** Save/reopen/undo restore inputs; changes mark design stale.

## Explicit non-goals (this slice)

- Serviceability checks (**M07-S**)
- LTB / weak-axis flexure expansion beyond accepted S2 (**M07-LTB**)
