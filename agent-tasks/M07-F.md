## UX rules required here

- Status hierarchy for **strength** path: PASS / FAIL / UNSUPPORTED / INDETERMINATE / STALE / NOT CHECKED / missing input / analysis failure (textual, not colour-alone).
- **Why** navigation on FAIL: governing combination → station → demand/resistance → assumptions → clause (Rust trail).
- Keyboard/table path for select → edit inputs → run → inspect details.
- Serviceability: show **out of scope / not checked** until [M07-S](M07-S.md) — do **not** invent service utilisations.

## Acceptance (DW-F1–DW-F5)
