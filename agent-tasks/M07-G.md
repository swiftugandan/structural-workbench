# M07-G — Whole-model steel review, catalogue, and section study

Status: PLANNED. Parent: M07. Depends on: [M07-F](M07-F.md).  
Maps to steel design pack **§31 Phases 7 and 9** and approved mockups **03–05**.

## Outcome

Steel design scales beyond one member: overview, bulk/groups, batch runs, catalogue assignment UI, and transparent section studies with explicit apply + reanalysis.

## Scope (owned only here)

| Pack phase | Work |
| --- | --- |
| 7 Whole-model | Batch design; overview table; Model Explorer design-status counts; filters; utilisation/status overlay |
| 9 Section studies | Catalogue browser filters; deterministic candidate loop; reanalysis when stiffness/self-weight change; comparison; explicit Apply; undo; incomplete-search semantics |

Also: bulk assignment / design groups; hierarchical calculation reports for multi-member runs; revision/hash-addressable design results; **what-changed** after Apply.

## Acceptance (DW-G1–DW-G6)

- **DW-G1 Batch:** Progress, cancel, partial results; UI stays responsive.
- **DW-G2 Overview:** Tree / table / viewport status agree; next-failure navigation works.
- **DW-G3 Bulk/groups:** Multi-select assign with preview/undo; group inconsistency visible.
- **DW-G4 Catalogue:** Supported vs unsupported families visible before assignment.
- **DW-G5 Study:** Candidate table + Apply + reanalysis when required + what-changed; truncated search ≠ optimum.
- **DW-G6 Reports/history:** Hierarchical export; stale vs current distinguished by hash/revision.
