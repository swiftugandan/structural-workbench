# M07-S — Steel serviceability (deferred)

Status: PLANNED (deferred). Depends on: [M07-F](M07-F.md); may run parallel with [M07-G](M07-G.md).  
Maps to steel design pack **§31 Phase 8**. Binding: ADR 0008.

## Outcome

Strength and serviceability are separately evaluated and displayed (criteria, service combinations, distinct PASS/FAIL), without blending into one utilisation.

## Acceptance

- **DW-SVc1:** Service criteria + service combinations produce a status distinct from strength utilisation; never one blended PASS/FAIL for both.

## Non-goals

Does not expand strength clause families; does not imply M09 second-order service drifts unless analysis provides them. Does not own inspector shell migration (M07-F) or section study (M07-G).

## Gate until accepted

M07-F/G must label serviceability as **not in scope / not checked**, never a silent PASS.
