  supports, loads, numeric coordinates and units; explicit working planes.
- Full authoring state: collecting inputs, cursor/snap preview, Enter commit,
  Escape cancel; visible world-aligned grid; 8 CSS-pixel snap priority and stable ties.
- Clear unconnected crossings and near-coincident warnings with no silent joins.
- Selected-member axes; split/connect/merge previews with physical lineage and
  loads preserved; failed topology commands atomic; exact undo/redo.
- Selection click/Shift toggle/blank-drag box selection; pan/orbit/Plan/Elevation,
  cursor-centred zoom, Fit/Home, scoped keyboard shortcuts and table alternatives.
- Dependency-preview deletion and atomic multi-selection editing.
- B05/B06 and independent 4×3 portal oracle; rotation, translation, relabel,
  reorder and endpoint-reversal invariance; instability/repair; report and reopen.

- A real M01 verifier reading same-build evidence, required test IDs and artifact
  hashes, including fail-closed tests for missing/stale/failed evidence.
