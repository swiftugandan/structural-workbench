# Catalogue and finite candidate study

Actual kernel calculations only. Independent cantilever self-weight expectations use published source areas 14.7, 18.2 and 29.1 in², 7850 kg/m³, 3 m length and 9.80665 m/s². Expected member mass is rho A L and fixed-end moment is mass g L / 2. No expected actions are supplied to the kernel.

Native regression checks exact candidate result/model provenance, baseline nonmutation and duplicate rejection. Browser journey imports a synthetic loading model, assigns a real verified catalogue section through the UI, confirms user assumptions, analyses, compares two selected candidates, downloads actual records, applies explicitly, checks stale state, undoes, reapplies/reanalyses and exports the project.

All results retain the existing AISC S2 scope. A finite subset comparison does not prove global optimality or full building-code compliance. Real British concrete design remains separately resource blocked.
